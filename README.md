## 📌 Project Overview

Employee attrition is a significant challenge for organizations, leading to increased recruitment costs, productivity loss, and reduced workforce stability. This project leverages Machine Learning techniques to predict whether an employee is likely to leave the company based on various workplace, demographic, and performance-related factors.

Using the IBM HR Analytics Employee Attrition dataset, the project performs comprehensive data preprocessing, exploratory data analysis (EDA), model training, evaluation, and feature importance analysis to generate actionable HR insights.

---

## 🎯 Objectives

- Analyze employee data to identify patterns associated with attrition.
- Build predictive machine learning models for employee attrition.
- Compare multiple classification algorithms.
- Identify the key factors influencing employee turnover.
- Provide business recommendations that support HR retention strategies.

---

## 📂 Dataset

**Dataset:** IBM HR Analytics Employee Attrition Dataset

The dataset contains employee-related information such as:

- Age
- Department
- Job Role
- Monthly Income
- Job Satisfaction
- Work-Life Balance
- Years at Company
- Overtime
- Performance Rating
- Education
- Environment Satisfaction
- and several other HR-related attributes.

Target Variable:

- **Attrition**
  - Yes → Employee Left
  - No → Employee Stayed
